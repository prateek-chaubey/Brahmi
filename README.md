<h2 align=center> ब्राह्मी · Brāhmī  · 𑀩𑁆𑀭𑀸𑀳𑁆𑀫𑀻 </h2>

A single-page web app that converts text between **Devanagari** and the ancient **Brahmi script** in real time — the script Ashoka's edicts were carved in, and the ancestor of nearly every major Indic writing system used today.

No build step, no dependencies. Just HTML, CSS, and vanilla JS.

## Web App
https://prateek.is-a.dev/Brahmi/

## Features

- **Transliterate** — live, two-way conversion between Devanagari and Brahmi, with a one-tap swap.
- **Brahmi Keyboard** — type Brahmi character by character; tapping a consonant shows its matra row so you can complete the akshara in one tap.
- **Practice** — read classic Hindi tales in Devanagari with a live Brahmi mirror below; click any word to highlight it in both scripts.
- **About** — background on the script and how the conversion works.

Conversion follows the official [Unicode Brahmi block](https://www.unicode.org/charts/PDF/U11000.pdf) (U+11000–U+1107F) and runs entirely in the browser — nothing is sent to a server.
